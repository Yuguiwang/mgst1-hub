Mgst1 — ENCODE CSHL batch 1 (unmodified ENCODE files)

No reprocessing. Every track streams the original ENCODE bigWig directly from the ENCODE public S3 bucket. No file in this hub was generated, rescaled, merged, or averaged. Replicates are shown separately, exactly as ENCODE released them.

Important — these ENCODE signal files are already RPM-normalised by ENCODE's own pipeline. The bulk RNA-seq pipeline runs STAR with --outWigNorm RPM, so values are reads per million uniquely-mapped reads, not raw read counts (values are non-integer, and the genome-wide signal sum is near-constant across libraries despite differing sequencing depth). ENCODE does not distribute un-normalised bigWigs; producing those would require re-processing the BAMs, which is exactly what this hub avoids. Track heights are therefore already depth-comparable.

Contents

17 tissues × 2 biological replicates = 34 tracks. Single batch: 76 bp reads, submitted 2012-02-29 / 2012-06-29, mm10 + GENCODE M21, pipeline bulk-rna-seq-star-signal-generation-step-v-1-0, lab Thomas Gingeras (CSHL), C57BL/6, adult 2 months. Because all libraries share one read length, one submission window and one pipeline version, exon-ratio comparisons across these 17 tissues are valid — unlike the 101 bp batch (cerebellum, cortical plate, frontal cortex, placenta, urinary bladder), which is deliberately excluded here.

Signal type: plus strand signal of unique reads. Mgst1 is a plus-strand gene, so minus-strand files carry no Mgst1 signal (verified: minus-strand mean over the locus ≈ 0).
